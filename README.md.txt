# Zepto Inventory & Sales Analysis Dashboard

## Project Overview
This project analyzes Zepto inventory, discounts, pricing, and stock availability using SQL and Tableau.

## Tools Used
- PostgreSQL
- SQL
- Tableau Public

## Key Insights
- Top discount products identified
- Revenue analysis by category
- Inventory weight analysis
- Stock availability analysis
- Price-per-gram efficiency analysis

## Dashboard Features
- Bar Charts
- Pie Charts
- Scatter Plot Analysis
- Inventory Insights

- SQL Queries
- Tableau Dashboard
